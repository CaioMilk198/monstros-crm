# MONSTROS AI 3.0 — TESTE DE SIMPLIFICAÇÃO

Esta versão preserva o Supabase, as importações, as tabelas e os módulos da 2.6.1.

## O que mudou

- Menu principal reduzido para Hoje, Equipe, Vendedores, Evolução e Administração.
- Centro de Comando transformado em uma tela de decisão com até três prioridades.
- Separação visual entre ação financeira, desenvolvimento e reconhecimento.
- Atalhos internos mantêm acesso à Sala de Guerra, Director, Coach, Ligações, Timeline, Academy e Monstrão.
- Valores de oportunidade passam a ser apresentados como estimativas aproximadas na tela Hoje.

## Como atualizar

1. Faça backup do repositório atual no GitHub.
2. Envie todo o conteúdo desta pasta para a raiz do repositório `monstros-crm`.
3. Confirme o commit na branch `main`.
4. Aguarde a publicação automática da Vercel.
5. Abra o sistema e pressione Ctrl + F5.

## Banco de dados

Não execute arquivos SQL e não altere o Supabase para testar esta versão.

## Como voltar

Republique o ZIP da versão 2.6.1 ou reverta o commit no GitHub.
