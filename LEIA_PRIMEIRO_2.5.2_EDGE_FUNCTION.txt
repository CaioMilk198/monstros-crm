IMPORTANTE: o ZIP do site NÃO publica sozinho uma Edge Function no Supabase.
Depois de substituir os arquivos do site, você precisa publicar UMA VEZ a função `monstros-ai` no Supabase e cadastrar a OPENAI_API_KEY.

PASSO MAIS FÁCIL PELO DASHBOARD SUPABASE:
1. Abra seu projeto no Supabase.
2. Vá em Edge Functions.
3. Clique em Deploy a new function > Via Editor.
4. Nome: monstros-ai
5. Apague o exemplo e cole TODO o conteúdo de:
   supabase/functions/monstros-ai/index.ts
6. Clique em Deploy function.
7. Vá em Edge Functions > Secrets (ou Project Settings > Edge Functions/Secrets, conforme sua tela).
8. Crie o secret OPENAI_API_KEY com a sua chave da API OpenAI.
9. Volte ao MONSTROS AI, faça Ctrl+F5 e abra Ligações & QA.
10. O topo deve mostrar: “● IA conectada e pronta”.

Se aparecer “Edge Function online • falta configurar OPENAI_API_KEY”, a publicação deu certo e falta apenas o secret.
Se aparecer “IA offline • Edge Function não alcançada”, a função ainda não está publicada no projeto correto.
